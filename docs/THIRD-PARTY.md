# Third-party dependencies

This source bundle includes the Razorpay PHP SDK 2.9.3 at `vendor/razorpay/`. Its upstream repository is https://github.com/razorpay/razorpay-php and its original MIT license is preserved at `vendor/razorpay/LICENSE`.

The SDK also bundles Requests 2.0.4, whose license is preserved at `vendor/razorpay/libs/Requests-2.0.4/LICENSE`.

The project's original source used JetFormBuilder and third-party payment integrations as **architecture references**. Before distributing the plugin under an open-source license, confirm the copyright/provenance of all originally authored code and preserve relevant third-party notices.

No blanket license for the project's own source has been selected in this review candidate.
